## Design Context

### Users

The interface is shared by the operator and ordinary buyers. Everyone arrives with an iCloud Hide My Email address and a high-entropy access token; the operator uses the same flow for personal verification mail so this Cloudflare mailbox can replace QQ/IMAP completely. People usually arrive while waiting for a sign-in code and need to authenticate, recognize the newest message, copy its code, and leave within seconds. The same page must remain comfortable on a phone, where most lookups happen under mild time pressure.

### Brand Personality

Private, calm, dependable. The product should feel like a small personal letter box rather than an infrastructure dashboard, security product, or marketing landing page. Copy is concise Chinese, reassuring without being playful, and never exposes implementation jargon unless the user can act on it.

### Aesthetic Direction

A restrained paper-and-ink mailbox: warm tinted neutrals, deep blue-black text, one vermilion stamp accent, editorial serif display type paired with a clean CJK-capable body stack. Light and dark themes follow the operating system. Avoid neon, glassmorphism, generic gradient hero sections, excessive cards, and decorative technical imagery.

### Design Principles

1. Put the email-and-token task first; every secondary detail yields to fast retrieval.
2. Make message freshness and the verification code legible at a glance without hiding the body.
3. Treat privacy as visible product behavior: no browser storage, no token in URLs, clear session and retention copy.
4. Preserve full functionality on small screens with 44px touch targets and deliberate single-column reflow.
5. Use plain language, strong focus states, reduced-motion support, and safe text-only email rendering.
