## 遇到的坑

- 列表请求中包含 Apple 登录 Cookie，不能直接执行整个附件或将其写入日志、Git。仅解析允许的 HTTPS 列表请求，凭据留在进程内。
- 当前 HME Session 按单账户保存；替换为另一账户并全量对账可能影响已有地址，新增批次应走独立登记路径。
- Apple 列表中的转发目标为 iCloud 母号，服务实际监控后续转发收件箱；二者地址不同不能单独判断收信是否正常。
- API 鉴权通过、邮箱登记成功、邮件实际到达是不同的验证层次，不能用 HTTP 200 / `waiting` 代替新邮件到达验收。
- 新增地址之前已经推进的收信游标不能盲目回退；历史邮件重新导入可能被赋予新的收件时间。
