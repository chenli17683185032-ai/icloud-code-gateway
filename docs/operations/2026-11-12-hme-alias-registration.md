## 遇到的坑

- Apple HME list 返回隐藏邮箱地址，不返回邮件正文；成功取得列表不等于 API 已登记。
- 当前 HME Session 按单账户保存，直接导入其他账户的 Session 可能影响原账户的同步状态，应使用独立邮箱登记路径。
- 邮件到达母号后，尚未登记的隐藏地址不会被云端收件逻辑匹配；收信桥推进游标不等于该地址已经保存了邮件。
- 现有邮件导入接口将导入时刻作为收件时刻，不宜盲目重放旧验证码，避免旧邮件被当作新验证码。此次登记不回退游标或批量重放历史邮件。
